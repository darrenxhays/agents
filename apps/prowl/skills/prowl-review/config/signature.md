# PR-Owl Review — Signature

How the reviews and comments this skill posts are signed. Edit the two blocks below to change it. To keep your version across updates, copy this file to `~/.prowl/config/signature.md` (or `$PROWL_HOME/config/signature.md`) and edit that copy instead.

## Review banner

Every review body starts with this block, with `<verdict>` and `<batch-id>` filled in. Keep it in a fenced `text` block so GitHub keeps the spacing.

````markdown
```text
  ,_,
 (O,O)    PR-Owl Review
 (   )    <verdict>
 -"-"-    <batch-id>
```
````

## Comment prefix

Every inline comment, and every reply on an existing thread, starts with this text:

```text
🦉 **PR-Owl Review** · 
```
